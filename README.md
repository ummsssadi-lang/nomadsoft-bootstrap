# NomadSoft Solutions: Bootstrap 5 quiz site

Author: Adisbek Umai

A single-page, responsive website for a fictional IT company that builds custom software. It uses Bootstrap 5.3.8 (CSS and bundle JS from the CDN) and Bootstrap Icons, with no jQuery and no other frameworks. All five required sections (`#home`, `#services`, `#case-studies`, `#about`, `#contact`) are on `index.html`: a collapsing navbar, a hero with a CTA, three service cards, four case studies that open in modals, an about block with stats, a validated contact form with a success alert, and a footer.

Bonus features included: scrollspy on the navbar, a testimonials carousel, a client logos strip, and a sticky sidebar for case studies on lg+ screens. Custom CSS is kept to a small `assets/styles.css` (brand colours, the decorative band, and a few sizes). All images are SVG files made for this project; company names, quotes, and numbers are sample content.
